# 对应召唤与素材履历

在场上以特殊召唤生成或编辑怪兽时，可勾选“作为融合／同调／超量／连接／仪式召唤”，再打开素材与移动履历。融合、同调、超量、连接要求来源为额外卡组；仪式召唤不限制召唤来源。“是否正规召唤”仍单独控制苏生限制。

可搜索生成素材实例，或选用局面中已有的怪兽。每项保存素材卡片、持有者、来源玩家／区域／位置／表示、去向玩家／区域／位置／表示。来源与去向按卡片类型过滤：例如仪式怪兽不能进入额外卡组，融合／同调／超量／连接怪兽不能放入手牌或主卡组。超量素材固定叠放在召唤的怪兽下方；其他召唤可配置送墓等合法去向。

这不是纯文字记录：怪兽的实际素材组、召唤类型、素材的移动原因及来源资料都会更新，并运行素材检查、素材被使用时的连续处理及怪兽自身的召唤成功初始化。真红眼龙骑士使用两只／一只／零只通常素材时，相关次数标记会分别重新初始化；I:P 作为连接素材会赋予实际的效果破坏抗性。修改既有怪兽而未改变素材履历时，不重复生成或移动素材。

主卡片与素材修改作为同一步提交，撤回、前进和跨会话存档保留这组操作。素材仍可通过原有超量素材编辑入口单独管理；该入口仅管理叠放，不会凭空声明一次超量召唤。移除履历条目不会自动删除或还原其此前已移动的实体卡片。

编辑器不检查具体卡片的完整召唤配方，适合人为构造测试局面。当前素材初始化支持无需玩家作出选择的连续处理；若素材脚本在初始化中要求选择卡片或作出其他交互，会拒绝整组提交并保留原局面。此类情况请通过正常召唤流程完成，尚不能宣称覆盖所有卡片脚本。

验证：MDPro3 共享核心 128 项断言，Mono 框架同组 128 项通过；YGOPro 实际核心 625 项断言。两版实际界面验证素材搜索、配置、生成、履历回填、整组撤回与前进。Mono 完整本体启动与界面验证仍待目标机确认。
