# 0.2.6：自定义连接怪兽的实际连接关系

自定义箭头已参与显示和连接数计算，但核心的连接区域、连接卡片集合、互相连接区域和互相连接卡片集合仍检查原卡类型。原本不是连接怪兽的卡片即使编辑为连接，也不会被这些关系查询接受，导致狮鹫等依赖连接状态的效果判断错误。

四处查询现统一读取编辑后的类型，同时保留实际位置及离场状态的检查。修复同步至 YGOPro 与 MDPro3 的共享核心；MDPro3 的显示刷新修复继续保留。

真实脚本回归：对方场上梦幻崩影狮鹫，己方鲜花女男爵先处于未连接状态，确实不能发动；生成原本为青眼白龙的自定义连接怪兽指向女男爵，核心查询确认女男爵已连接，狮鹫不再禁止其发动；移开箭头后限制恢复；再次指向后，通过实际发动选项与目标选择，女男爵效果成功破坏狮鹫并将其送去对方墓地。

YGOPro 真实核心完整回归通过 609 项断言，MDPro3 会话核心回归通过 83 项断言。两版的相关核心源码相同。Mono 完整游戏启动验证仍需目标机器完成。
