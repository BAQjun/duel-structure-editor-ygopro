# 原版引擎卡片状态审计

共核对 32 个卡片状态位和 256 个效果代码；引擎保留 89 个有本卡读取路径的常量效果；界面去重并按当前卡片类型筛选显示。

状态位与效果来源分开处理：无效、攻击/发动限制等由真实效果施加；撤回和存档保留整个执行过程。流程位会与连锁、Lua 协程、处理队列及卡片关系一起恢复，只读的全量查看页已移除；流程标记随实际过程恢复，不作为独立选项。
