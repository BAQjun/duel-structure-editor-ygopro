# 0.2.4：自定义连接怪兽的表示限制

表示变更能力检查原先读取原卡类型，导致原本不是连接怪兽的卡片在编辑为连接后，仍保留手动变更表示的权限。

修复后，手动表示变更、效果表示变更、里侧盖放、特殊召唤表示筛选和进场表示处理均按编辑后的类型判断。自定义连接怪兽只能保持表侧攻击表示；恢复普通怪兽类型后重新允许正常的表示变更。该核心修复已同步到 MDPro3 和 YGOPro 两个版本。

验证：YGOPro 真实核心 589 项断言通过，新增用例覆盖手动能力查询、效果能力查询、特殊召唤表示筛选、实际处理器拒绝守备与里侧，以及离开连接形态后恢复权限。MDPro3 的 IL2CPP / Mono 两种框架下各 80 项核心断言通过。Mono 完整游戏启动的既有限制不变。
