# 路径配置与迁移

运行程序不要求指定盘符。个人开发目录不属于项目的安装要求。

## YGOPro 存档与图库

默认存档位于程序目录的 `userdata/saves`。`editor-data.conf` 第一行可以写相对路径，例如 `userdata/saves` 或 `../shared-saves`，也可以写目标电脑上的绝对路径。相对路径基于程序所在目录解析，不受启动时工作目录影响。支持中文、空格及 UTF-8 BOM 配置。网络共享路径可配置，但仍受网络可达性和用户权限限制。

已有配置的绝对路径会继续使用，不自动移动、删除或合并旧存档。旧版更新后若想改用便携目录，请先备份旧存档，再复制到新目录并修改配置；多个版本需要共用存档时，可以显式指定同一个目录。更换盘符后应检查绝对路径配置。

卡图可放在包内 `pics`、`expansions/pics`，也可在 `card-images.conf` 添加自己的图库。新发布包不预置开发者图库位置。Windows 系统字体目录由系统接口查询，不假定系统安装在某一盘符。

## MDPro3 安装

安装器不再预填开发者的游戏位置。如果安装器本身就在包含 `MDPro3.exe` 的目录中，会识别该目录；否则使用“浏览”选择本体。存档继续保存在所选 MDPro3 本体的数据目录内。

## 源码构建

复制 `build-config.example.json` 为 `build-config.local.json`，填写当前电脑的工具和依赖位置。该本地配置被 Git 忽略，不要上传。环境变量 `DUEL_EDITOR_<键名大写>` 优先于 JSON 配置，最后使用项目内默认位置。JSON 内相对路径以项目根目录为基准，不要求将仓库放在指定盘符。

常用键：

- `python`：Python 可执行文件，默认使用 PATH 中的 `python`。
- `llvm_mingw_bin`、`premake`：编译工具位置，默认使用项目 `tools` 中的配套目录。
- `unity_data`：Unity 安装目录下的 `Editor/Data`；未配置时尝试 Unity Hub 的标准安装位置。
- `game_root`：构建 MDPro3 IL2CPP 扩展及安装器时所需的兼容本体目录。
- `ygopro_root`：构建 MDPro3 原生核心时使用的 YGOPro 源码与 Lua 依赖目录。
- `ygopro_runtime`：运行共享核心测试所用的兼容脚本夹具所在目录；应与已准备的测试数据库匹配。
- `asset_root`：准备 YGOPro 运行包时的数据库和可选卡图来源。
- `runtime_root`：基础运行包准备工具的输出目录。
- `csc`：可选的 .NET Framework 编译器位置；安装器构建默认根据系统目录查找。

修改配置即可使用自己的依赖位置，无需批量修改源码。工具链、游戏程序集、卡片脚本和数据库仍需另行准备；目录可配置不代表任意依赖版本都兼容。

验证：YGOPro 628 项真实核心断言，包括中文／空格路径的存档写入、名称读取和载入；相对路径、其他盘符、UNC 路径解析及配置优先级检查通过。运行包已迁移至中文且含空格的目录，实际界面生成与回溯测试通过。MDPro3 共享核心及 Mono 框架各 128 项断言通过。
